# E-Commerce Sales & Customer Behaviour Analysis

## Project Overview
This project analyzes e-commerce sales and customer behaviour using SQL Server and Power BI. The analysis focuses on sales performance, customer purchasing patterns, product performance, customer segmentation, RFM analysis, and cancellations.

## Tools Used
- SQL Server
- Power BI

## Objectives
- Clean and prepare e-commerce transaction data
- Analyze sales and customer behaviour
- Identify top-performing products and countries
- Analyze repeat and one-time customers
- Segment customers based on revenue
- Perform RFM analysis
- Analyze cancelled orders
- Build an interactive Power BI dashboard

## Dataset
The dataset contains online retail transaction data with information such as invoices, products, quantities, prices, customers, countries, and transaction dates.

## Data Cleaning
The raw dataset contained 541,909 records. After cleaning invalid and incomplete records, the cleaned dataset contained 392,692 records.

The cleaning process included:
- Removing missing product descriptions
- Removing zero or negative quantities
- Removing zero or negative unit prices
- Removing records with missing Customer IDs
- Handling duplicate records
- Calculating Sales Amount as Quantity × Unit Price

## Key Analysis
- Overall sales and order performance
- Monthly sales trends
- Country-wise sales
- Top products
- Customer purchasing behaviour
- Customer segmentation
- RFM analysis
- Cancellation analysis

## Dashboard
Power BI was used to create interactive dashboards for:
- Executive Overview
- Product & Customer Analysis

## Key Insights
- The UK generated the highest revenue.
- Repeat customers accounted for approximately 66% of customers.
- November 2011 was the strongest complete month by revenue.
- High-value customers contributed a significant share of total revenue.
- Cancellation activity represented a notable amount of potential sales value.

## Project Outcome
The project helped demonstrate practical skills in SQL data cleaning and analysis, customer segmentation, RFM analysis, and Power BI dashboard development.
